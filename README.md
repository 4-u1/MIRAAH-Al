## 📌 ملخص المشروع (Executive Summary)

منظومة **"مرآة" (MIRAAH)** هي حل تقني ابتكاري وطني مُصمم لرفع كفاءة أعمال التصفية والبيع في **مركز الإسناد والتصفية (إنفاذ)**، من خلال رقمنة وأتمتة عمليات معاينة وتوثيق الأصول العقارية الخاضعة للتصفية القضائية والمزادات.

يقوم المشروع بتحويل المعاينة التقليدية البطيئة وعالية التكلفة إلى **تجربة رقمية تفاعلية لحظية** مدعومة بالذكاء الاصطناعي (AI) وتقنيات التوأم الرقمي (3D Digital Twin)، وإصدار **جواز الأصل العقاري الرقمي (Digital Asset Passport)** الموثق رقمياً والمحمي بهاش مشفر (SHA-256 Tamper-Proof) بالمواءمة التامة مع **كود البناء السعودي (SBC)**، الهيئة السعودية للمقيّمين المعتمدين (**تقييم**)، ووزارة العدل.

## 🏆 المواءمة مع معايير التحكيم بالبرنامج (صفحة 14)

### 1. جودة الحل المقترح وتعريف المشكلة والقيمة المضافة (10%)
- **المشكلة:** المعاينة التقليدية للأصول تحت التصفية تستغرق وقتاً طويلاً، تعتمد على تقارير ورقية مبعثرة، وتفتقر للشفافية الفورية مما يسبب تردد المشترين وتأخر المزادات أو انخفاض أسعار الترسية.
- **الحل والقيمة المضافة:** توحيد بيانات الأصل العقاري في "جواز أصل رقمي" فوري يقلص وقت تجهيز ملف الأصل بنسبة **70%**، ويرفع ثقة المزايدين والمستثمرين.

### 2. التوافق مع الأولويات الوطنية وقابلية قياس الأثر (10%)
- يدعم مستهدفات **رؤية السعودية 2030** في:
  - رقمنة المنظومة العدلية وسرعة استرداد الحقوق.
  - تعزيز الشفافية في المزادات القضائية الحكومية والتجارية.
  - تطبيق معايير كود البناء السعودي (SBC) لحماية الثروة العقارية الوطنية.

### 3. مستوى الابتكار وجدة الفكرة (15%)
- الدمج غير المسبوق بين:
  - **التوأم الرقمي ثلاثي الأبعاد للأصل (Digital Twin)**.
  - **التحليل الذكي للعيوب الإنشائية وتقدير تكاليف معالجتها**.
  - **سجل البصمة المشفرة للوثائق (Tamper-proof Cryptographic Verification)**.

### 4. الجدوى التقنية والتنفيذية والنموذج الأولي (25%)
- **نموذج أولي حقيقي وقابل للتشغيل الفوري (Functional Working Prototype)**:
  - مبني بأحدث حزم التقنية: React 18، TypeScript، Vite، Tailwind CSS، و Three.js / Canvas.
  - لا يعتمد على واجهات وهمية؛ جميع الإحصائيات، التباديل، التصدير، والوثائق تعمل بكفاءة تامة.

### 5. الاستدامة والجدوى الاقتصادية ونموذج العمل (20%)
- تقليص تكاليف اللجان الميدانية والمعاينات المكررة.
- رفع القيمة التقديرية للأصل عند البيع بنسبة تتراوح بين **12% - 22%** نتيجة الشفافية وإزالة "مخاطر المجهول" لدى المزايدين.
- إمكانية تبني المنصة كنموذج SaaS مدمج مع منصة إنفاذ والمزادات المعتمدة.

### 6. قابلية التوسع والتبني (10%)
- معمارية برمجية مفتوحة ومرنة تدعم الربط عبر واجهات البرمجة (REST APIs) مع:
  - منصة إنفاذ (Infath API).
  - البورصة العقارية وبوابة ناجز (وزارة العدل).
  - الهيئة العامة للعقار والهيئة السعودية للمقيّمين المعتمدين (تقييم).

### 7. جودة العرض التقديمي ووضوح المحتوى (10%)
- تصميم واجهة متطور وعالي الأناقة (Dark Navy & Emerald/Cyan Palette) مستوحى من الهوية الوطنية والمؤسسية المعتمدة لمركز إنفاذ مع دعم كامل للشاشات المتجاوبة والأجهزة اللوحية.

## 🛠️ المكونات الوظيفية الرئيسية في النظام

```
src/
├── components/
│   ├── AssetPassport/         # بطاقة وجواز الأصل العقاري الرقمي والمؤشرات
│   ├── SpatialTwin/            # التوأم الرقمي ثلاثي الأبعاد ومخطط المعاينة
│   ├── Inspection/             # سجل فحص العيوب الإنشائية وبنود كود البناء SBC
│   ├── Documents/              # خزينة الصكوك والوثائق المعتمدة (Accredited PDF Viewer)
│   ├── ExportPassport/         # محرك تصدير الجواز بصيغ PDF / CSV / JSON
│   ├── Simulation/             # محاكي What-If لقرارات التصفية وتكاليف المعالجة
│   └── Verification/           # سجل التوثيق والاعتماد والتشفير الرقمي
├── types.ts                    # نماذج البيانات المتوافقة مع متطلبات إنفاذ
├── utils/scoring.ts            # محرك حساب مؤشرات الجاهزية والخطر
└── App.tsx                     # نقطة الربط والتكامل الرئيسية
```
